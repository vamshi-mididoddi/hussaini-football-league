HFL. Score console

Connect to publish

Scores publish straight to the website through GitHub. Paste your access token once — it stays in this browser only.

How to create the token (one time, 2 minutes)
  1. On github.com (logged in as the repo owner) go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it hfl-admin, set expiry after the season ends.
  3. Repository access: Only select repositories → hussaini-football-league.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy the github_pat_… value, paste it above.

Treat the token like a password — anyone holding it can edit the site.
